**ATP-WTA Report**



All'interno di questa directory si trova un file ATP-WTA-Report.pbix contenente il report vero e proprio realizzato con power bi desktop.



**Come navigare all'interno del report?**

Il report è strutturato emulando la struttura di una partita di tennis: nella pagina principale sono riportate alcune informazioni generali sull'analisi svolte; sulla sinistra sono disposte sei palline da tennis numerate che servono per navigare all'interno del report, queste rappresentano i sei games che compongono un set di una partita di tennis.



Cliccando su ciascuna pallina all'utente viene mostrata la pagina iniziale di un altro set di pagine tutte inerenti ad una stessa tematica analizzata. Per muoversi all'interno di questo sotto gruppo di slides, si possono utilizzare le 4 palline sulla sinistra 0, 15, 30, 40, come i punti di un game.



La pallina numero 0 riporta sempre alla pagina di home, mentre le altre servono a navigare all'interno della stessa tematica.



**Come è stato svolto il lavoro?**

Il dataset di partenza è stato scaricato dai seguenti repositories: https://github.com/JeffSackmann/tennis\_atp e https://github.com/JeffSackmann/tennis\_wta. 



I dati sono poi stati opportunamente manipolati in python, dove sono state creati i files csv da importare in power-bi.



In power-query sono state effettuate le ultime operazioni di pulizia dei dati, e in power-bi sono state realizzate le connessioni tra le tabelle.
